HOST THIS APP ON RENDER
=======================

1. Push this project to GitHub or GitLab.

2. Go to https://render.com and sign in.

3. Click:
   New +  >  Blueprint

4. Select the GitHub/GitLab repository that contains this project.

5. Render will read the included render.yaml file automatically.

6. Confirm the service settings:

   Service type: Static Site
   Publish directory: ./static
   Build command: leave blank

7. Click Apply or Deploy Blueprint.

8. Wait for the build to finish. Render will provide a URL similar to:
   https://xai-decision-support.onrender.com

9. Open that URL to use the app.

The legacy HTTP API uses server.py, but it binds to localhost:8000 and is not
the backend used by the current static site. The static site calculates results
in the browser and requires no backend service.

NOTES
-----
- No environment variables or build command are required.
- The static site runs the scorecard in the browser and does not require a Python server.
- app.py and server.py are retained as separate server-based versions of the project.
- On Render's free plan, the service may sleep after inactivity and take a short time to wake up.
- This is a prototype using synthetic data. It should not be used as the sole basis for lending, clinical, or investment decisions.
